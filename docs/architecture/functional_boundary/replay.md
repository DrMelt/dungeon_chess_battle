# DungeonChessBattle.Replay

回放引擎：纯本地确定性重跑录制输入，零网络依赖。与 Battle.Server 录制端、Replay.Server 服务侧、Replay.Client 获取端共同构成回放子系统。

## 职责

- 回放解码与确定性重建：接已解码的回放记录，按元数据与单位初始态重建战斗场景；校验录制端内容与逻辑两项修订号，任一不符拒绝重放；副本键须在本地内容中可解析，非法或未注册同样拒绝。归档不合规范与内容引用不成立一律以原因交回调用方，不留半启动状态。
- 确定性驱动：固定逻辑步长推进，记录条目还原为玩家命令后按帧注入输入门面，注入先于意图刷新，自治决策与位移由战斗世界计算。
- 事件流输出，以及单位、副本键与开始时刻、帧轴时钟等世界读数，供 Game 层表现层数据源装配。
- 输入条目时间轴：三类归档条目按帧混排成只读投影，供 UI 定位当前帧前后的输入。
- 播放控制：播放/暂停/倍速，支持从任意时间点确定性跳转。

## 边界外

- 不依赖网络，不含回放下载与本地存储：获取链路归 Replay.Client。
- 不实现 UI 场景与入口，展示与控制在主工程。
- 不做字节流解码，交进来的记录已解码：字节流层门控归 Replay.Shared 的格式定义，本层构建入口复核修订号、副本键、单位引用与移动轨道规范。
