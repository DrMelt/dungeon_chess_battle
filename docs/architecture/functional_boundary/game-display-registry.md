# DungeonChessBattle.Game.Display.Registry

展示注册表库：四类条目展示数据的读写口与实现同库。不内置任何条目，也不认识 mod——条目一律由装配方写入，装配完即只读。客户端专用，服务端程序集不携带；读写口随本库发布，mod 展示代码经引用链可见。

## 职责

- 条目展示数据注册表：技能、Buff、单位、副本四类同键覆盖，对装配方给出登记面，对消费方给出读面。
- 同键覆盖为字段级：后注册者声明了什么就改什么，未声明字段沿用被覆盖者。
- 注册表以实例交出，不持全局状态：由装配方创建，随装配产物交宿主组合根持有。

## 边界外

- 不做装配编排：创建注册表、装载展示代码、挂载资源包与执行入口的次序在 Game.Mod.Manager。
- 不认识 mod：注册约定、入口接口与包管理都不在本库。
- 不定义展示数据形状：四类展示数据在 Game.Shared，内容身份键取自 Battle.Shared。
- 不含装配上下文与表现接口：在 Game.Mod.Shared。
- 不做装配期校验：按 mod 归属校验展示引用的内容键是否存在由装配面做，本库只存查。
- 不含管理面：mod 扫描、启停与错误汇总在 Game.Mod.Manager。

## 依赖

- Game.Shared、Battle.Shared。
