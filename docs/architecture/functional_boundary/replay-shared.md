# DungeonChessBattle.Replay.Shared

回放归档格式定义库。服务端导出与客户端下载解析共用的容器格式、数据模型与编解码，独立于网络协议层。

## 职责

- 自包含分块容器：校验与压缩、未知块跳过；版本门控内建于解码路径。
- 回放内容模型：元数据、单位初始态、按玩家分轨的方向意图段、施法与聚焦条目。
- 只读元数据入口：不解码整档即可取元数据。
- 玩家命令与归档条目的双向映射唯一权威：折叠判据与轨道成型在此，录制端只持时间轴与账本。

## 边界外

- 不含录制与重跑：录制在 Battle.Server，重跑在 Replay 引擎。
- 不含归档的查询、凭证与下载，归 Replay.Server 与 Replay.Client。
- 归档的写入与检索不在本库，归 Server.DataStore.Shared；摘要即元数据。
- 不依赖网络栈，格式独立于传输通道。
