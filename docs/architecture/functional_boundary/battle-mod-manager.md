# DungeonChessBattle.Battle.Mod.Manager

mod 包管理面与数据面内容装配：包布局、清单与启用集、目录装载、入口装载、内容指纹与内容装配引导。纯 .NET 类库，被 Server.Host 与 Game.Mod.Manager 引用。

## 职责

- 定义包布局：清单与启用集的位置、默认目录；产物位置由 mod 清单声明，未声明回落默认目录。
- 清单与启用集的读写。
- 目录装载：按启用集与依赖顺序装载，失败目录单独列出。
- 路径裁决：越界与语法非法整包拒载，数据面产物缺失整包拒载，展示面产物缺失只记装载期错误。
- 路径安全判定：清单声明与 mod 资源寻址共用的根目录内相对路径约束。
- 入口装载：逐 mod 隔离装载入口程序集，装载与实际执行分阶段。
- 内容指纹：按数据面范围计算，展示代码与展示资源不入指纹。
- 错误归属：错误带归属 mod 与原因。
- 内容装配引导：以扫描结果装配数据面内容，单个 mod 失败不中止其余，装配产物交回调用方。

## 边界外

- 不定义注册约定：入口接口在 Battle.Mod.Interface，注册面在 Battle.Mod.Shared；本库实现注册面并调 mod 入口。
- 不持有注册表：实现在 Battle.GameConfig，本库每次装配新建，产物以实例交回调用方。
- 不感知展示面语义：注册进什么表由 Game.Mod.Manager 决定。
- 不做战斗与网络，不与引擎交互。

## 依赖

- Battle.GameConfig 与 Battle.Mod.Interface：前者承载注册表，后者承载数据入口接口，注册面定义随之传递可见。
- 通用装载机制只用 .NET 基础类库：装配引导是本库唯一接触注册约定的部分。
