# DungeonChessBattle.Battle.Mod.Manager

mod 包管理面与数据面内容装配：包布局、清单与启用集、目录装载、入口装载、内容指纹与内容装配引导。纯托管类库，被 Server.Host 与 Game.Mod.Manager 引用。

## 职责

- 定义包布局：清单与启用集的位置；产物位置必须由清单显式声明，未声明即拒载。
- 清单与启用集的读写。
- 清单校验：只校验数据面字段，未知顶层键与缺失必填字段一律拒载，原因带字段名。
- 目录装载：按启用集与依赖顺序装载，失败目录单独列出。
- 根级裁决：根目录不可用与启用集不可读按一个都不装载处理，原因随装载结果交回调用方，不静默。
- 路径裁决：越界与语法非法整包拒载，数据面产物缺失或读不出整包拒载。
- 路径安全判定：清单声明与 mod 资源寻址共用的根目录内相对路径约束。
- 入口装载：逐 mod 隔离装载入口程序集，装载与实际执行分阶段；装载输入是入口程序集与探测目录，不区分调用方是数据面还是展示面。
- 内容指纹：按数据面范围计算，展示代码与展示资源不入指纹。
- 错误归属：错误带归属 mod 与原因。
- 启停读写：启用集读不出、写不进按原因交回调用方，不打断调用方所在的那一步。
- 过程日志：扫描、入口装载与内容装配按自身类别名写入宿主注入的日志通道；两端装载同一批 mod，日志可逐阶段比对，逐条明细按调试级别记录。
- 内容装配引导：以扫描结果装配数据面内容，单个 mod 失败不中止其余；被拒的注册按 mod 归属收进装配期错误，引导上下文向 mod 交出日志通道；装配产物交回调用方。

## 边界外

- 不定义注册约定：入口接口在 Battle.Mod.Interface，内容注册接口在 Battle.Mod.Shared；本库实现注册接口并调 mod 入口。
- 不持有注册表：实现在 Battle.Config.Registry，产物以实例交回调用方。
- 不解释展示面语义：清单模型只登记展示段键的存在，使未知键拒载不误判展示段；段内容与裁决全归 Game.Mod.Manager，本库不读不验不传递。
- 不做战斗与网络，不与引擎交互。

## 依赖

- Battle.Config.Registry、Battle.Mod.Interface。
