# DungeonChessBattle.Battle.Shared

战斗域共用形状层：跨端数据与标识、只读视图与行为端口。只声明形状，不含配置数值与可变状态。纯 .NET 类库，零项目引用，是全链路的叶子。

## 职责

- 内容身份与单位标识：跨端一致的内容身份强类型与长度上限，注册表、协议与展示面共用同一约束。
- 只读数据形状：单位战斗数值快照、Buff 视图、仇恨条目与倍率、伤害与治疗的结算结果、领域事件。
- 行为端口：技能效果、Buff 效果、单位自治决策与仇恨规则的实现口，由内容包实现，引擎只按定义引用调用。
- 意图形状与意图源口：单位当帧意图的形状与其产出者接口，玩家输入与自治决策同形，实现由引擎承担。
- 规格接口：Buff 的引擎消费形状，由内容定义实现。技能规则不在此暴露：技能集以键暴露，判定与结算由引擎按身份解析。
- 只读视图与能力问答：单位与战场的只读查询形状，施法可行性以按身份的问答暴露，不接收外部构造的技能对象。
- 输入形状：玩家命令的载体形状，输入门面在 Battle.Logic。
- 纯形状计算与常量：范围几何判定的形状口、向量运算、战斗阶段与阵营关系映射。

## 边界外

- 不含静态配置数据：内容定义与其注册表查找口在 Battle.Config.Shared。
- 不含运行时实体与权威状态：单位领域实体、冷却与仇恨账本的读写面、装配与展示视图在 Battle.Runtime.Shared。
- 不含行为实现与编排：效果算法、自治决策算法与仇恨规则实现在内容包，节拍、意图刷新与裁定在 Battle.Logic。
- 不依赖网络与引擎，不做序列化与网络载体。
