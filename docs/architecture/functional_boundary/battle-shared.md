# DungeonChessBattle.Battle.Shared

契约与数据结构层。定义战斗、Buff、仇恨、移动、阵营、事件、敌人决策所需的数据类型与端口契约，零项目引用，无网络与 Godot 依赖。

## 职责

- 契约与数据结构：技能/Buff/范围/单位快照/战斗单位/玩家命令/领域事件族与端口接口所需的数据类型。
- 端口契约：Buff 效果、技能效果、单位视图、战斗场景视图、敌人决策、仇恨规则、移动场景等接口。
- 引擎能力问答：施法可行性以只读查询暴露，内容侧据此决策。
- 纯数据固有计算：范围几何判定、向量运算、阵营关系映射。
- 行为 ID 常量：mod 注册/覆盖/扩展行为的键，与引擎预置展示资源名同构。
- 内容注册表只读视图：按技能键 / BuffTypeId / 单位配置键 / 副本键查领域定义，供展示面与只读消费方判据。
- 回放结算逻辑修订号：结算时序的版本指纹，供录制与重放门控比对；递增义务在 Battle.Logic，见 `functional_boundary/battle-logic`。

## 边界外

- 不含战斗编排、Buff 节拍、位移解算、仇恨分发与施法/目标校验判据，均在 Battle.Logic。
- 不含内容侧逻辑实现：技能与 Buff 效果、伤害治疗公式、敌人决策算法由内容包提供，本层只给它们的端口与行为 ID。
- 不依赖网络与 Godot，不做序列化与网络载体。
- 不猜未知关系：阵营组合未覆盖时返回未知。

## 依赖

- 无：纯 .NET 类库，零项目引用。
