# DungeonChessBattle.Battle.Shared

接口与数据结构层。定义战斗、Buff、仇恨、移动、阵营、事件、敌人决策所需的数据类型与接口，零项目引用，无网络与引擎依赖。

## 职责

- 接口与数据结构：技能、Buff、范围、单位快照、战斗单位、玩家命令与领域事件所需的数据类型。
- 接口：Buff 效果、技能效果、单位视图、战斗场景视图、敌人决策、仇恨规则与移动场景。
- 引擎能力问答：施法可行性以只读查询暴露，内容侧据此决策。
- 纯数据固有计算：范围几何判定、向量运算、阵营关系映射。
- 内容注册表只读视图：按内容身份键查领域定义并暴露内容修订号，供展示面与只读消费方判据。
- 回放结算逻辑修订号：结算时序的版本指纹，供录制与重放门控比对；递增义务在 Battle.Logic，见 [battle-logic](battle-logic.md)。

## 边界外

- 不含战斗编排、Buff 节拍、位移解算、仇恨分发与施法、目标校验判据，均在 Battle.Logic。
- 不含内容侧逻辑实现：技能与 Buff 效果、伤害治疗公式、敌人决策算法、仇恨规则与阵营关系函数由内容包提供，本层只给它们的端口。
- 不依赖网络与引擎，不做序列化与网络载体。
- 不猜未知关系：阵营组合未覆盖时返回未知。

## 依赖

- 无：纯 .NET 类库，零项目引用。
