# DungeonChessBattle.Lobby.Protocol

大厅协议唯一权威来源。服务端与客户端两侧共用，消除大厅协议字符串与 DTO 魔法值。

## 职责

- 协议常量：大厅长连接端点路径、方法名与默认监听端口。
- 网络 DTO：大厅请求与结果、招募板条目、房间快照。
- 登录结果携带的会话凭证：登录成功后服务端签发，供服务端 HTTP 端点自证身份。

## 边界外

- 不含业务实现与运行时逻辑，纯 .NET 类库，无第三方运行时依赖。
- 不含字段长度约束，归 Battle.Shared。
- 回放记录格式与编解码，归 Replay.Shared；回放协议，归 Replay.Protocol。
- 不受理连接建立与重连，连接事件由大厅与房间两端各自实现。

## 依赖

- Lobby.Shared。
