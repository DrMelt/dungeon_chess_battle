# DungeonChessBattle.Battle.GameConfig

内容装配宿主库。全部内容由 mod 程序集提供，本库负责装配、注册表与行为目录，不持有任何内容定义。纯 C#，服务端与客户端共用同一套装配结果。

## 职责

- 内容装配：创建领域注册表与行为目录，内容修订号退化为引擎固定常量。
- 消费数据面装载结果，逐 mod 装载数据入口，把内容和行为注册进空注册表。
- Buff/Skill/Unit/Dungeon 领域定义注册表与索引，同键覆盖；暴露只读视图，供展示面与只读消费方查询。
- 技能/Buff 效果、敌人决策、仇恨规则、阵营关系的行为目录，引擎不内置行为。
- 引导上下文：`IModEntry` 实参，行为与内容注册转发到目录/注册表。
- 单位与副本的权威登记点。
- 以单位配置装配战斗单位领域实体。

## 边界外

- 不做权威裁定：施法与目标可行性判据在 Battle.Logic，本层经场景视图的只读查询取结论。
- 不做战斗编排：节拍推进、事件顺序、意图消费与状态写回均在 Battle.Logic。
- 不提供内容：无内置单位/技能/Buff/副本，零 mod 环境注册表为空。
- 不含运行时反射：内容为编译期拼装的定义对象。

## 依赖

- Battle.Shared；Battle.Mod.Manager、Battle.Mod.Interface 与 Battle.Mod.Shared。不依赖 Battle.Logic，引用方向单向朝下。
