# DungeonChessBattle.Battle.GameConfig

内容配置库：领域定义的注册表、行为目录与单位目录。不内置任何内容，也不认识 mod——内容一律由装配方写入。纯 C#，服务端与客户端共用同一份注册结果。

## 职责

- Buff、Skill、Unit、Dungeon 领域定义注册表，同键覆盖；暴露只读视图，供展示面与只读消费方查询。
- 装配产出：一次装配的内容注册表与建在其上的单位目录，以实例交装配方持有。
- 行为目录：行为 ID 到行为实现，引擎不内置行为。
- 单位目录：按配置键取单位配置。副本不设目录口，按内容键查定义与枚举副本都走注册表。
- 以单位配置装配战斗单位领域实体。

## 边界外

- 不做内容装配编排：创建注册表、装载 mod 入口与写入次序的流程在 Battle.Mod.Manager。
- 不认识 mod：注册约定、入口接口与包扫描均不在本库。
- 不做权威裁定：施法与目标可行性判据在 Battle.Logic，本层经场景视图的只读查询取结论。
- 不做战斗编排：节拍推进、事件顺序、意图消费与状态写回均在 Battle.Logic。
- 不持全局状态：跨层取用由组合根注入或经组合根取用。
- 不提供内容：无内置单位、技能、Buff 与副本，未装配时不存在可用注册表。
- 不含运行时反射：内容为编译期拼装的定义对象。

## 依赖

- Battle.Shared。引用方向单向朝下，不依赖 Battle.Logic，也不依赖任何 mod 库。
