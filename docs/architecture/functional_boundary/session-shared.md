# DungeonChessBattle.Session.Shared

会话标识库。存放会话期由服务端生成、跨大厅协调、状态存储与客户端会话共用的房间标识值类型，使会话标识不落在任何单一域的形状库中。

## 职责

- 房间标识的值语义：构造时校验长度上限，支持空值判定与字符串取值，与字符串双向隐式转换。
- 值相等以字符串取值为准，空值与空串视为同一个值。

## 边界外

- 不含业务实现与状态，只放房间标识的值语义。
- 不承载网络协议、实体同步线缆、回放格式与传输路由：这些边界仍以字符串携带房间标识，协议与格式定义归 Lobby.Protocol、Battle.Entities 与 Replay 各库。可信来源直接构造本类型，客户端提交、线缆同步与路由参数等不可信来源先经判定构造。
- 不承载战斗内容身份与玩家身份，内容身份键归 Battle.Shared，玩家身份归身份存储。

## 依赖
