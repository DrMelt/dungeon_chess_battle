# DungeonChessBattle.Session.Shared

会话标识库。存放会话期由服务端生成、跨大厅协调、状态存储与客户端会话共用的房间标识值类型，使会话标识不落在任何单一域的形状库中。

## 职责

- 房间标识的值语义：构造时校验长度上限，提供空值判定、字符串取值、双向隐式转换与供不可信输入的 <c>TryCreate</c> 判定。
- 值相等以字符串取值为准，空值与空串视为同一个值。

## 边界外

- 不含业务实现与运行时逻辑，纯 .NET 类库，零项目引用。
- 不承载网络协议、实体同步线缆、回放格式与传输路由：这些边界仍以字符串携带房间标识，格式定义分别归 Lobby.Protocol、Battle.Entities 与 Replay 各库。字符串进本类型时，可信来源走隐式转换，客户端提交、线缆同步与路由参数等不可信来源先经 <c>TryCreate</c> 判定。
- 不承载战斗内容身份与玩家身份，内容键归 Battle.Shared，玩家身份归身份存储。

## 依赖

- 无。
