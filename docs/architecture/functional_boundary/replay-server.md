# DungeonChessBattle.Replay.Server

回放服务侧。承担回放列表与字节流的 HTTP 端点、会话凭证鉴权与参与者校验；不含身份签发与录制。

## 职责

- 端点映射：注册列表与下载两条路由，宿主只负责调用。
- 凭证鉴权：会话凭证经身份解析端口换成玩家记录主键，换不到即未授权。
- 查询与取档：取归档字节流并按玩家主键校验参与者，非参与者与不存在的回放同回不存在。

## 边界外

- 不承载长连接，也不签发凭证：凭证由大厅登录签发与撤销，本库只解析。
- 不拥有身份体系：玩家记录主键由身份解析端口给出。
- 不实现录制与归档写入：录制与归档在 Battle.Server；存储实现在 Server.DataStore。
- 不解释回放内容：只取归档元数据作摘要，不解码输入轨道、不重放；重放在 Replay 引擎与客户端。

## 依赖

- Replay.Protocol、Replay.Shared、Server.DataStore.Shared、Session.Shared。
