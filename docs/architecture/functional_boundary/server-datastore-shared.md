# DungeonChessBattle.Server.DataStore.Shared

服务器数据存储抽象。定义大厅级房间与玩家准备状态的存储契约与快照模型，不绑定具体存储实现。

## 职责

- 存储门面，组合房间数据存储与玩家数据存储两个子接口。
- 房间数据存储：注册/查询房间、招募板列表、密码校验、状态与人数维护、清理。
- 玩家数据存储：成员归属、登录会话与会话凭证、准备状态、房主转让与准备单位。
- 回放归档存储端口 `IReplayStore`：以房间 ID 为主键写归档字节流与参与者记录主键、按玩家检索、按房间取字节。
- 身份解析端口 `IPlayerIdentityResolver`：会话凭证 → 玩家记录主键。
- 房间与准备状态的快照数据模型。

## 边界外

- 不包含具体存储实现，持久化方案在装配层替换。
- 不纳入网络连接密钥与战斗房间会话。
- 战斗单位状态不在此模型，由战斗世界权威持有。
- 归档内容与摘要不在此层，归 Replay.Shared。

## 依赖

- Lobby.Shared（房间状态枚举）。
