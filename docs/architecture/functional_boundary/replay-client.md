# DungeonChessBattle.Replay.Client

回放获取侧。只向服务端取回放事实：服务端归档摘要列表与单场归档字节流下载。

## 职责

- 服务端列表：取服务端归档摘要列表，服务端侧不可用降级为空列表。
- 字节流下载：读取单场归档，回报进度、支持取消与超时；未授权、不存在与网络失败分类返回。
- 结果形状只含传输语义：成功、未授权、不存在、网络失败四态与下载结果。

## 边界外

- 不做本地缓存、条目枚举、解码、内容版本门控与列表并集：归主工程。
- 不构建战斗世界、不推进帧、不含播放控制，重放在 Replay 引擎。
- 不含 UI、节点与屏幕切换，呈现在主工程。
- 不建立连接、不登录、不签发凭证：服务器根地址与会话凭证由使用方提供。
- 不定义回放归档存储接口，归 Server.DataStore.Shared，实现在 Server.DataStore。

## 依赖

- Replay.Protocol。
