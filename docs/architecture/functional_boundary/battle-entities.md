# DungeonChessBattle.Battle.Entities

实体同步网络实体层。服务端与客户端共用的网络实体类型、类型注册表与协议载荷，另承载两端共用的网络默认值与子进程跨进程启动约定。

## 职责

- 房间、单位与控制实体的网络实体类型。
- 实体类型注册表与同步字段类型注册。
- 协议载荷：可靠请求、同步数据、战斗事件日志与消息帧。
- 单位与领域单位之间的状态同步通道，两端各按自身方向使用。
- 网络默认值与子进程跨进程启动约定：默认端口、连接密钥与环境变量名，两端共享单一来源。
- 网络框架日志转发到统一日志体系。

## 边界外

- 不实现战斗结算与规则，权威在战斗世界。
- 不映射为 UI 事件，翻译由客户端战斗实体映射层承担。
- 不含连接管理与会话逻辑。
