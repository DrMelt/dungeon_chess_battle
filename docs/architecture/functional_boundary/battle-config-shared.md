# DungeonChessBattle.Battle.Config.Shared

战斗静态配置数据层：开局前即可由内容包读出的配置形状与其查询接口。纯托管类库。

## 职责

- 内容定义：技能、Buff、单位与副本的配置形状，含技能全局冷却、范围形状与单位自治决策声明。定义只读、无运行时状态，持内容侧行为实现引用，数值随实现自持。
- 单位基础数值：装配期携带的不变基础数值，运行时实体引用它取基础值。
- 内容注册表只读视图：按内容身份键查领域定义并暴露内容修订号，供展示面与只读消费方判据。
- 战场布局配置：竞技场尺寸与障碍区域。

## 边界外

- 不含共用形状：身份键、只读数据形状、行为接口、规格接口与只读视图在 Battle.Shared。
- 不含运行时实体与权威状态，在 Battle.Runtime.Shared。
- 不做注册：内容定义的唯一登记接口在 Battle.Config.Registry，装配编排在 Battle.Mod.Manager。

## 依赖

- Battle.Shared。
