# DungeonChessBattle.Lobby.Client

大厅客户端，长连接传输。只承载大厅与准备阶段的请求与广播回调，不含实体同步。

## 职责

- 建立连接、发起大厅与准备阶段请求。
- 事件派发：房间创建与加入、快照更新、招募板列表、重定向与连接状态事件。
- 保留服务端签发的会话凭证，供上层透传。

## 边界外

- 不包含战斗房间客户端与网络实体系统。
- 不含回放：回放获取归 Replay.Client 与主工程，本层只交出一个连接级凭证。
- 回调以自身线程送达，不保证主线程；线程转接归客户端门面。
- 不定义协议，端点方法与大厅 DTO 归 Lobby.Protocol。

## 依赖

- Lobby.Protocol、Session.Shared。
