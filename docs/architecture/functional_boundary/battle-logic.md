# DungeonChessBattle.Battle.Logic

战斗逻辑实现层：实现战斗世界并编排战斗节拍，承担权威裁定，只面向领域类型，不依赖网络，公式与决策算法由内容包实现。

## 职责

- 战斗编排：推进阶段、读条、冷却、Buff 与技能结算，产出领域事件流。
- 意图刷新与投递：按世界注册顺序逐单位刷新意图源并经世界写入接口投递，只提供只读查询供自治决策询问。
- 意图源登记：按驱动轨道分别登记，走哪条轨道由生成单位的宿主裁定，本层不从内容配置推断。
- 权威输入门面：玩家命令的唯一入口，命令转写为该单位意图源的输入，并按帧单点推进意图刷新。
- 权威状态：自持单位权威状态，供外送侧读取。
- Buff 节拍、施法与目标校验、范围目标裁定、仇恨与位移的落地逻辑。
- 递增逻辑修订号；内容修订号随内容变化。

## 边界外

- 不依赖网络与实体载体：无事件编码与传输，网络同步与领域事件外送由服务端承担。
- 不含客户端表现与输入采集，预输入不进同步通道。
