# DungeonChessBattle.Server.DataStore

服务器数据存储实现。当前唯一实现为进程内版本。

## 职责

- 实现存储接口：房间与玩家两侧的读写，含密码、房主、准备状态、连接归属与准备单位。
- 实现回放归档存储接口：进程内归档与玩家记录索引，受保留场数上限约束。
- 持有登录会话与会话凭证，会话身份解析就地完成。
- 兑现接口承诺的同房间读改写原子性，对外读提供快照。

## 边界外

- 不含业务逻辑，大厅与战斗业务由上层消费。
- 战斗单位状态不进入存储，由逻辑层权威持有。

## 依赖

- Server.DataStore.Shared、Battle.Shared、Lobby.Shared。
