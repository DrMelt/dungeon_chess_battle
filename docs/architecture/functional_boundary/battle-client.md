# DungeonChessBattle.Battle.Client

房间战斗客户端，走网络传输与实体同步。管好网络实体，以单一会话接口向上外露。

## 职责

- 管理网络实体生命周期，把服务端实体事件翻成上层可消费的接口事件，经单一会话接口外露。
- 持有当前房间的战斗事件日志，只读外露。
- 上送施放、聚焦与移动请求。
- 以服务端下行为准维护本地单位读数，作为展示与判定的唯一取数源。
- 内容一致性：战斗期服务端引用的副本或单位不在本地内容中即放弃本地战斗世界并上报，由装配层退出战斗；本端不做缺内容的降级呈现。

## 边界外

- 不实现战斗结算、读条、伤害、冷却与仇恨，全部服务端权威。
- 不为 UI 实现业务，上层只消费会话接口；连接生命周期不在该接口内，归客户端门面。
- 不含大厅阶段能力。
