# DungeonChessBattle.Server.DataStore

服务器数据存储实现，所属分组 Server。当前唯一实现为基于并发字典的进程内版本。

## 职责

- 实现存储契约：房间配置、密码、房主、准备状态、连接归属、玩家标识映射与准备单位表。
- 实现回放存储契约：进程内回放归档、玩家记录索引与最近场数上限。
- 以房间级锁串行化同房间读改写，对外提供只读快照。

## 边界外

- 不含业务逻辑，大厅与战斗业务由上层消费。
- 战斗单位状态不进入存储，由逻辑层权威持有。

## 依赖

- Server.DataStore.Shared（契约）、Protocol（常量）、GameConfig（默认副本键）、Lobby.Shared（房间状态枚举）。
