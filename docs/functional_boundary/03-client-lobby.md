# DungeonChessBattle.Client.Lobby

大厅客户端，SignalR 传输，所属分组 Client。只承载大厅与准备阶段的请求与广播回调，不包含 LES 实体系统。

## 职责范围

- 构建 `HubConnection`、注册服务端回调、发起大厅与准备阶段请求。
- 事件派发：房间创建/加入、快照更新、招募板列表、重定向、连接建立与关闭、重连失败。
- 缓存房间快照供进房初始化读取。

## 不负责

- 不包含战斗房间客户端与 LES 实体系统。
- 不在回调线程触碰客户端状态：信号回调都在 SignalR 后台线程触发，消费方负责转主线程。
- 不定义协议契约，Hub 方法名、DTO 与字段约束归 Protocol。


## 依赖项

- Protocol（Hub 方法名、DTO 与字段约束）。
