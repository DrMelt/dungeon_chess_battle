# DungeonChessBattle.Client

网络客户端门面与连接状态机，所属分组 Client。向下组装大厅与房间两个连接客户端，向上对 Godot 层暴露统一连接模型。

## 职责

- 持有大厅与房间两个持久连接客户端，实例不外泄：对外只给契约、只读快照与请求方法，连接发起权力由本门面独占。
- 维护连接状态机，覆盖大厅与房间两端的连接、切换与重连。
- 断线重连：以持久玩家身份为凭据，经服务端校验后重连并恢复战斗。
- 战斗会话生命周期：连接房间成功触发战斗启动，会话丢失触发退出战斗。
- 将两端客户端事件转换为 C# 事件，对 Godot 层暴露统一请求入口。

## 边界外

- 不实现 SignalR 与 LiteNetLib 具体传输。
- 不含大厅与战斗业务逻辑，只做连接编排。
- 不含回放获取：列表、下载、缓存与解码归回放获取侧（`Replay.Client` 出网、Game 层浏览服务编排）；本门面只透传连接级会话凭证，不解释它被谁消费。
- 不在后台线程触碰传输对象，回调统一转主线程。

## 依赖

- Client.Shared、Lobby.Protocol 契约；Lobby.Client 与 Battle.Client 两端经连接工厂创建。
