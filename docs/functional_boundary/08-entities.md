# DungeonChessBattle.Battle.Entities

LES 网络实体层，所属分组 Shared。服务端与客户端共用的实体类型、类型注册表与协议载荷。

## 职责

- 房间、单位与控制实体的 LES 网络实体类型。
- 实体类型注册表与自定义同步字段类型注册。
- 协议载荷：可靠请求、同步数据载荷、战斗事件日志与可靠消息帧编解码。
- 单位实体只读视图适配，供客户端技能预拦与展示。

## 边界外

- 不实现战斗结算与规则，权威在战斗世界。
- 不映射为 UI 事件，翻译由客户端战斗实体映射层承担。
- 不含连接管理与会话逻辑。

## 依赖

- Protocol、Battle.Shared。
