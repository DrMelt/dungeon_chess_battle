# DungeonChessBattle.Entities

LES 网络实体层，所属分组 Shared。服务端与客户端共用的实体类型、类型注册表与协议载荷。

## 职责范围

- 网络实体：房间实体与单位实体为状态投影载体，承接战斗世界投影的 SyncVar；控制实体承担玩家输入提交与可靠请求通道。
- 类型注册表与自定义同步字段类型注册，LES 日志转接。
- 协议载荷：可靠请求、同步数据载荷、战斗事件日志编解码与可靠消息帧编解码。
- 移动输入流注入与可靠请求订阅。
- 单位实体只读视图适配：客户端技能预拦与展示数据源经 IBattleUnitView 只读投影 SyncVar。
- 服务器 tick 换算工具：倒计时同步统一为截止 tick，服务端载体与客户端 UI 共用推算。

## 不负责

- 不实现战斗结算与规则，权威在战斗世界。
- 不映射为 UI 事件，翻译由客户端战斗实体映射层承担。
- 不含连接管理与会话逻辑。


## 依赖项

- Protocol、Battle.Domain。
