# DungeonChessBattle.Protocol

网络契约唯一权威来源，所属分组 Shared。服务端与客户端两侧共用，消除协议字符串、端口与字段长度魔法值。

## 职责

- 网络契约常量：Hub 方法名、协议字符串字段约束与网络默认值，两端共用。
- 网络 DTO：大厅请求与结果、招募板条目、房间快照、回放列表与回放下载凭证。
- 客户端连接最小契约，供门面统一驱动。
- 跨进程启动契约：服务端子进程启动参数与环境变量约定。

## 边界外

- 不含业务实现与运行时逻辑，纯 .NET 类库，无第三方运行时依赖。
- 不含业务默认值与配置域常量，默认副本键归 GameConfig。
- 不含回放记录格式与编解码，归 Replay.Shared。
- 不受理连接建立与重连，连接事件由大厅与房间两端各自实现。
- 战斗周期消息结构由 LES 实体类型系统表述，不定义于本层。

## 依赖

- Lobby.Shared（房间状态枚举）。
