# DungeonChessBattle.Protocol

网络契约唯一权威来源，所属分组 Shared。服务端与客户端两侧共用，消除协议字符串、端口与字段长度魔法值。

## 职责范围

- Hub 方法名常量：客户端调用、服务端广播回调与 Hub 方法绑定共用。
- 网络默认值：大厅监听端口、房间端口 LES 二进制包头与默认连接密钥，客户端与服务端共读。
- 协议字符串字段长度约束与默认副本键，服务端校验与客户端 UI 限制共享；GameConfig 不反向依赖本层。
- 网络 DTO：大厅请求、请求结果、招募板条目、房间快照、回放列表与回放下载凭证；登入请求登记服务端权威玩家名，回放查询与下载以登录会话为身份依据。
- 回放数据契约：回放记录模型与快照、基于 MessagePack 的编解码，服务端导出与客户端下载解析共用；显式索引与格式版本门控，格式不依赖网络栈。
- 客户端连接最小契约，供门面统一驱动。

## 不负责

- 不含业务实现与运行时逻辑，纯 .NET 类库，无第三方运行时依赖。
- 不受理连接建立与重连：连接与完全连接/断开事件由大厅与房间两端实现各自提供，契约仅保留最小连接状态与断连口。
- 战斗周期消息结构由 LES 实体类型系统表述，不定义于本层。


## 依赖项

- 仅 Battle.Domain。
