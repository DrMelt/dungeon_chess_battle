# DungeonChessBattle.Battle.Logic

战斗逻辑实现层，所属分组 Shared。实现战斗世界并编排战斗节拍，提供 Buff、仇恨、移动与战斗结算的具体逻辑，只面向领域类型，不依赖网络。

## 职责

- 战斗编排：推进阶段、读条、冷却、Buff 与技能结算，产出领域事件流。
- AI 决策：前置触发单位自治决策，动作经战斗世界统一调度。
- 施法预输入缓冲：`CastPreInputBuffer` 缓存玩家按键，状态就绪后交回战斗世界裁定。
- 权威状态：战斗世界自持单位权威状态，由服务端状态同步器写往网络载体。
- 提供 Buff、施法校验、伤害治疗、仇恨与位移的具体落地逻辑。
- 持有战斗移动场景，单位增删与场景注册同生命周期收敛。

## 边界外

- 不依赖网络与实体载体，网络同步由服务端状态同步器承担。
- 不含客户端表现与输入采集；输入排队状态不写进战斗世界与领域单位，战斗世界不感知预输入。
- 不含网络事件编码与传输，领域事件流由服务端外送。
