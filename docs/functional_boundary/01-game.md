# DungeonChessBattle.Game（Godot 主工程）

客户端工程，Godot 4.7 C#。场景、UI、战斗表现与网络驱动的最终装配层，不实现任何战斗规则与服务端业务。

## 职责

- 装配客户端服务与服务器子进程，驱动网络与输入。
- 路由战斗进出，统一编排战斗子系统生命周期与屏幕状态。
- 承载战斗会话数据与玩家操作，向 UI 与相机提供统一数据读取。
- 组装单位视图与技能展示资源，不对外提供数据查询。
- 经 `ResourceTables` 唯一入口读取技能/Buff/副本展示资源，场景模板依附资源文件，不经字符串路径直连资源。
- 采集战斗输入与目标拾取。
- 主菜单、大厅、房间准备、单位选择与战斗 HUD 等全部界面。
- 以子进程拉起与停止服务器，状态供 UI 查询。

## 边界外

- 不实现网络传输与连接状态机，全部委托大厅与战斗两个连接客户端。
- 不实现战斗结算、AI、仇恨与 Buff 规则，权威在服务端。
- 不承载服务端业务，服务器是独立子进程。
- UI 与会话投影层不持有网络对象：房间链路只消费 `IClientBattleSession` 契约与 C# 事件，诊断只消费快照 DTO；连接权力在门面，本层无绕过门面的连接入口。

## 依赖

- Client 及其 Lobby/Battle 两端；共享层 Lobby.Protocol、GameConfig、Battle.Entities、Battle.Shared 与 Battle.Logic。
