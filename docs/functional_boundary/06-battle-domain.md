# DungeonChessBattle.Battle.Domain

纯领域模型，所属分组 Shared。战斗结算、Buff、仇恨、移动、阵营、事件、敌人决策与数学的领域类型唯一权威定义层，无网络与 Godot 依赖。

## 职责

- 战斗、Buff、仇恨、移动、阵营、事件与敌人决策的领域类型唯一权威定义。
- 施法静态判定唯一来源，服务端权威校验、客户端预输入与 AI 决策共用。
- 敌人决策契约与默认实现，动作经战斗世界统一调度。
- 仇恨规则、Buff 实例模型、移动场景、阵营关系与领域事件流等规则族。

## 边界外

- 不依赖网络与 Godot，不做序列化与网络载体。
- 不实现具体编排，战斗推进由 Battle.Logic 承担。
- 不猜未知关系：阵营组合未覆盖时返回未知。

## 依赖

- 无：纯 .NET 类库，零项目引用。
