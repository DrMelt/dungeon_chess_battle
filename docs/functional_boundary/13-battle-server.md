# DungeonChessBattle.Battle.Server

战斗房间服务层，所属分组 Server。每个房间拥有独立的 LES 实体服务器与战斗世界，运行于独立线程。

## 职责

- 单房间战斗服务：独立网络、实体管理与战斗世界，独立线程固定步长驱动。
- 房间生命周期：创建/销毁、端口池分配回收与空房清理。
- 实现房间管理契约，向外只暴露端口等原语。
- 初始化：迁移准备期单位、按副本配置生成敌人并构建移动场景。
- 战斗循环：AI 与节拍推进、玩家输入进战斗世界、权威状态同步与事件外送。
- 玩家会话与断线重连：连接密钥校验与既有同名会话恢复。
- 战斗回放：收下玩家命令并旁路录制，房间销毁或关服时归档（摘要携带内容修订号），数据契约归 Replay.Shared。

## 边界外

- 不实现大厅业务与传输层广播。
- 不为客户端结算：结算权威都在战斗世界，客户端只有移动预测。
- 大厅线程不触碰实体管理器，只做生命周期控制。
- 不承担回放执行，只负责录制与归档。

## 依赖

- 共享层 Battle.Logic、Battle.Shared、Battle.Entities、GameConfig 与 Replay.Shared；存储层经数据存储契约；契约层 Server.Abstractions。
